OPERATORS:-
---------
1)Arithmetic Operator
2)Comparision Operator 
3)Assignment Operator
4)Relational Operator
5)Membership Operator
6)Identity Operator
7)Bitwise Operator

1)Arithmetic Operator:-
  -------------------
--> +, -, *, /, //, %, **

2)Comparision Operator:-
  --------------------
--><, >, <=, >=, ==, !=   ----> Result in Boolean form Either True or False

3)Assignment Operator:-
  -------------------
--> +=, -=, *=, %=, /=, //=, **=

4)Relational Operator:-
  -------------------
--> and, or, not         ----> Result in Boolean form Either True or False

5)Membership Operator:-
  -------------------
--> in, not in           ----> Result in Boolean form Either True or False

-->In Dictionary only it represents keys not values.

6)Identity Operator:-
  -----------------
--> is, is not          ----> Result in Boolean form Either True or False

eg:-
    l=[1,2,3,4]
    m=[1,2,3,4]
    id(l)
    2068520733248
    id(m)
    2068520339712
    l==m
    True
    l is m
    False
    n=m
    n
    [1, 2, 3, 4]
    n==m
    True
    id(n)
    2068520339712
    id(m)
    2068520339712
    n is m
    True
    m is n
    True
    n is l
    False
    n is not l
    True
7)Bitwise Operator:-
  ----------------
--> &, |, ^, ~, <<, >>
--> Left shift -- Add zeros
--> Right shift -- remove zeros

OUTPUT FORMATS:-
--------------
-->Comma Seperation 

 Eg:- a=10
      b=2.5
      c='codegnan'

      print("a=",a,"b=",b,"c=",c,sep='\t')
      a=	10	b=	2.3	c=	codegnan

-->f string

Eg:- print(f'a={a} b={b} c={c}')
     a=10 b=2.3 c=codegnan

-->format specifier

Eg:-print('a=%d b=%f c=%s'%(a,b,c))
a=10 b=2.300000 c=codegnan

-->format

Eg:-print('a={} b={} c={}'.format(a,b,c))
a=10 b=2.3 c=codegnan
print('a={} b={} c={}'.format(c,a,b))
a=codegnan b=10 c=2.3
print('a={0} b={1} c={2}'.format(a,b,c))
a=10 b=2.3 c=codegnan
print('a={2} b={0} c={1}'.format(a,b,c))
a=codegnan b=10 c=2.3
