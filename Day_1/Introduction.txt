PROCEDURE-ORIENTED PROGRAMMING(POP):-
-----------------------------------
-->Memory allocation is for functions and variables

->A program is divided into functions.
->when a function is called, memory is allocated for its local variables.
->After the function finishes, the allocated memory is released automatically.

EXAMPLE
-------

def display():
	x=10
	print(x)
display()

Memory Flow:-
-----------

	display() is called
		|
	Memory is allocated for x
		|
	display() finishes
		|
	Memory is released

OBJECT-ORIENTED PROGRAMMING(OOP):-
--------------------------------
-->In OOP, memory is allocated for objects.

->A program is divided into classes and objects.
->A class is only a blueprint, so no memory is allocated when the class is created.
->Memory is allocated only when an object is created.
->The object can access the data members and methods of the class.

Example:-
-------

class Student:
	def __init__(self):
		self.name="Vishnu"
s1=Student()

Memory Flow
-----------
	class student
	     |
     No memory allocation
	     |
     Object s1 is created
	     |
  Memory is allocated for s1

--->In OOP, memory is allocated only when an object is created.
